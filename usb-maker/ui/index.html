Kulan USB Maker

Makes a USB stick to install Kulan OS from.

1The USB stick

Use one of 4 GB or more. Everything on it is erased.

2Kulan OS

For an organisation using Kulan Fleet

Computers installed from this stick join your organisation by themselves the first time they’re online. Make a join code in Kulan Fleet (Computers, then Add computers) for as many computers as you’ll install.

3The computer you’ll install on

Getting Kulan OS

  1. Download Kulan OS and check it’s the real one
  2. Write it to the USB stick
  3. Check the USB stick
