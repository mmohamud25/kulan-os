# Kulan OS 3.0 plan (draft)

Decided with Mohamud, 23 October 2026. Nothing here reaches main or the
update channel until he says "release it".

## Kulan Editions (the headline)
One Kulan OS, four editions chosen in Kulan Installer and the Setup
Assistant ("What will you use this computer for?"; more than one can be
picked, and changed later in Kulan Settings › Editions). Not four ISOs: the
editions are what's added on top of the same system.
- Everyday (default): today's Kulan OS.
- Developer: the Kulan developer kit, Distrobox (apps from other Linux
  systems), the Terminal power tools.
- Gaming (PC only): Steam with Proton, GameMode, controller support, the
  right graphics drivers (NVIDIA included), and a graphics check that says
  plainly when a computer can't game well. Not offered on Arm (Mac).
- Work: join the organisation's Fleet during setup, compliance mode on,
  encryption required, and an automatic-install file for IT.
Website: a page and download button per edition, all the same ISO, starting
that edition's setup. Later, only if gaming takes off: a separate Gaming
ISO with NVIDIA drivers and Steam built in (one extra download, not four).
