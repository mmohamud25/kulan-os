# Kulan OS

Kulan OS is a desktop operating system by Kulan Group LLC: private, secure
and simple to use. It's built on Debian 13 with the GNOME desktop, for PCs
and laptops, and for ARM computers such as Apple silicon Macs (in a virtual
machine).

- **Download and install:** [os.kulangroup.com](https://os.kulangroup.com)
- **What's new:** [os.kulangroup.com/whats-new/](https://os.kulangroup.com/whats-new/)
- **Help:** [os.kulangroup.com/help/](https://os.kulangroup.com/help/), or email support@kulangroup.com
- **Report a security problem:** security@kulangroup.com

## What's in it

- **Kulan Settings:** every setting in one place, in plain words, with
  Software Update and a way to undo the last update.
- **Ask Kulan:** an assistant that runs on the computer itself. Nothing you
  type leaves it.
- **Private by default:** a firewall, disk encryption, ad and tracker
  blocking, and no tracking.
- **Kulan Fleet:** for organisations, to look after their computers and the
  people who use them.

## In this repository

The packages that make up Kulan OS, the scripts that build its ISO images,
the Kulan Fleet server and dashboard, Kulan USB Maker and the website.
[docs/building.md](docs/building.md) explains how to build, test and release it.
